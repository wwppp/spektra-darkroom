## 1. 怎么复现

```bash
# 生成参考网格 + 拟合钟形曲线，写入 tools/grain_params.json 与 tools/grain_reference.json
python tools/grain_reference.py

# 只验证可复现性，不重写 JSON
```

`--check` 的判定是**逐位相同**（`np.array_equal`），不是"近似一致"。

## 2. 参考网格

- 补丁 **192×192**（PSD 在有效径向区间内仍有 ≥64 个频段）
- 密度 **8 档**：`0.05, 0.15, 0.30, 0.50, 0.70, 0.95, 1.30, 1.80`（光学密度 D）
- 尺寸 **3 档**：长边 `5857 / 4685 / 3000` px，对应像素间距 `5.976 / 7.471 / 11.667 µm`（35 mm 画幅，口径与 `core/darkroom_math.grain_scale_px` 一致）
- 乳液参数取 spektrafilm 的 35 mm 彩色负片默认值：
  `particle_area_um2=0.2`、`particle_scale=[1.0,0.8,3.0]`、`density_min=[0.03,0.06,0.04]`、
  `density_max_curves=[2.2,2.2,2.2]`、`grain_uniformity=[0.98,0.98,0.98]`、
  `grain_blur=1.0`、`n_sub_layers=1`、`colour_grain=0.5`

### 2.1 σ(D) —— 颗粒度曲线（密度域，可直接对应渲染器的 `dD`）

`apply_grain_to_density` 工作在**光学密度**域，输出起伏本身就是 `dD`：

```
T_out = T_in · 10^(−dD)   ⟺   D_out = D_in + dD
```

因此测得的 σ 不需要任何换算就能和 `grain_model.density_response()` 对比。

| D | 0.05 | 0.15 | 0.30 | 0.50 | 0.70 | 0.95 | 1.30 | 1.80 |
|---|---|---|---|---|---|---|---|---|
| σ @5857 px | 0.0117 | 0.0165 | 0.0213 | 0.0256 | 0.0285 | **0.0295** | 0.0297 | 0.0238 |
| σ @4685 px | 0.0095 | 0.0132 | 0.0169 | 0.0205 | 0.0227 | 0.0239 | **0.0239** | 0.0190 |
| σ @3000 px | 0.0061 | 0.0086 | 0.0108 | 0.0129 | 0.0144 | **0.0154** | 0.0150 | 0.0122 |

曲线是**钟形**：趾部随曝光上升，中密度达峰，高密度回落。峰值密度随输出尺寸略向右移（0.81 → 0.88）。

### 2.2 频谱与高阶统计

| 指标 | 三档尺寸的实测范围 | 说明 |
|---|---|---|
| 径向 PSD 斜率 | **−1.82 … −2.07**（10–90 分位 −2.038 … −1.917） | 明显比白噪声（0.0）陡 |
| 峰度 | **2.96 … 3.11** | 基本高斯，无重尾 |
| 通道相关 | **0.781 … 0.797** | 对应 `colour_grain=0.5` 的方差保持混合 |

## 3. 拟合结果

对 σ(D) 归一化后拟合（参数写入 `tools/grain_params.json`）：

```
z = D − peak_density
w = width_shoulder  (z > 0)  else  width_toe
response = floor + (1 − floor) · exp(−0.5 · (z / w)²)
```

| 参数 | 5857 px | 4685 px | 3000 px | **跨尺寸均值（采用）** |
|---|---|---|---|---|
| `floor` | 0.000 | 0.000 | 0.000 | **0.0** |
| `peak_density` | 0.812 | 0.842 | 0.883 | **0.8456** |
| `width_toe` | 0.590 | 0.614 | 0.648 | **0.6177** |
| `width_shoulder` | 1.543 | 1.467 | 1.348 | **1.4528** |
| 最大残差 | 0.049 | 0.047 | 0.046 | 峰值的 ~5% |

`floor = 0` 是物理上正确的：密度为零时没有显影银颗粒，颗粒度必然为零。肩部宽度约为趾部的 2.35 倍，符合负片在高密度端缓慢压缩的行为。

**定义域约定**：渲染器的 `linear_rgb` 是场景线性曝光，`density_response()` 取
`D = −log10(clamp(lin, 1e-4, 1))`，即把 `linear_rgb` 近视为负片透射率。这与原实现
（`1 − exp(−lin / 0.010)` 在 `lin ≈ 0.03` 饱和）的口径一致，峰值落在 `lin ≈ 0.143`，即中灰附近。

## 4. 三条会改变后续计划的结论

### 4.1 PSD 斜率目标应为 **−1.98**，不是计划里写的 −0.8

计划第 3 节目标 G3 写的是「径向 PSD 斜率 ∈ [−0.7, −0.9]」，那是未标定时的估计。参考实现实测 **−1.98**（范围 −1.82 … −2.07），比估计陡得多。物理原因：`grain_blur` 在密度域做了 σ = 1.0 px 的平滑，而银盐颗粒的白噪声谱在 1 px 尺度上被强烈压制。

**当前渲染器实测 −1.34，比参考值"更白"**，即高频细节偏多。P2 的整形方向因此是**增加平滑**而不是减少。G3 的区间已按此更正。

### 4.2 通道相关目标 0.79，当前 0.886 偏高

参考实现 `colour_grain=0.5` 给出 0.79。当前渲染器 `grain_colour_rho(0.0115, 1.0)` 得 0.886，偏"亮度过重、彩噪不足"。P2.3 要把 rho 从「只由胶卷强度决定」改为「由层权重与密度共同推出」，并落在 0.79 附近。

### 4.3 振幅随分辨率变化，这一点与 P1 的验收标准冲突（**需要你决定**）

参考实现中，每像素密度噪声与像素间距成反比：

```
σ_D ∝ D_max / sqrt(n_particles_per_pixel) ∝ 1 / pixel_pitch ∝ long_edge
```

实测印证：5857 px 的峰值 σ 是 0.0297，3000 px 是 0.0154，比值 **1.93**（长边比 1.95）。这是正确的物理——采样越细，每像素覆盖的晶体越少，单像素噪声越大；缩小看时又被平均回来，观感不变。

而 P1 的验收写的是「80% 与 100% 下 σ 比 1.00±5%」，即**每像素振幅恒定**。两者不可能同时成立：

- **P1 口径（恒定）**：同一张图导出 100% 与 80%，逐像素颗粒强度一致。适合"图片按各自尺寸观看"。
- **物理口径（∝ 长边）**：100% 的逐像素噪声更强，缩略观看时被平均掉。适合"物理上正确的银盐"。

P1 已按恒定实现并通过（比值 1.0014）。本报告只把冲突摆出来，**暂不改动**。若你希望改为物理口径，P2 可以顺带把 `derive()` 的振幅乘上 `long_edge / 5857`，代价是 80% 导出的颗粒会变淡约 20%。

## 5. 过程中修掉的与已知的缺陷

| 类别 | 内容 |
|---|---|
| **我自己的 bug（已修）** | 参考生成器最初把**透射率** `10^-D` 当作密度传给 `apply_grain_to_density`，导致曲线随 D 单调下降（越黑的区域颗粒越少，物理上恰好相反）。改为直接传光学密度后曲线恢复钟形。 |
| **vendored 缺陷（未修，已知）** | `spektrafilm/model/grain.py:143` 的 `fixed_seed` 分支必然抛 `TypeError`：`fixed_seed is not None` 时把 `seed` 设为 `None`，随即执行 `seed[ch]`。P0 不使用该参数，靠默认种子 `[0,1,2]` 获得可复现性，因此没有改 vendored 代码。 |
| **可复现性依赖调用顺序** | `layer_particle_model` 内部调用 `np.random.seed(seed)` 设置**全局**随机状态。因此参考网格必须按 `DENSITY_GRID × LONG_EDGES` 的固定顺序生成；`--check` 已验证同序调用逐位相同。 |

## 7. P2 期间发现的判据错误（PSD 斜率）

P0 把「径向 PSD 斜率 ≈ −1.98」定为 P2 的频谱目标（当时的实测范围 −2.07 … −1.82，用 192 px 补丁）。P2 按这个目标把颗粒改粗后，A/B 对照图一眼就看出**不对**：参考是接近像素尺度的细密晶体，改粗后的实现是明显的云状斑块。

两个原因：

**7.1 估计量依赖补丁尺寸。** 同一份参考场：

| 补丁 | PSD 斜率 |
|---|---|
| 192 px | −2.01 |
| 384 px | **−1.74** |

小补丁对拟合的低频端覆盖不足，系统性偏陡。	ools/grain_stats.py 用 384 px，P0 原来用 192 px，两个数根本不可比。现已统一为 384 px，--check 仍逐位可复现。

**7.2 单一斜率无法区分不同纹理。** 参考是「白噪声 × 1 px 高斯」：低频平坦、高频陡降；我们的实现是「三个宽高斯之和」：整体平滑得多。二者在拟合窗口内可以给出相同斜率，但观感完全不同。**PSD 斜率不适合当外观门禁。**

**7.3 改用自相关半宽。** 参考的径向自相关半宽是 **1.81 px，且不随密度变化**（0.15/1.30/2.00 三档均为 1.81–1.82）。这个数直接回答「颗粒有多粗」，与眼睛判断一致：

| 配置 | 自相关半宽 | PSD 斜率 |
|---|---|---|
| 参考（粒子模型） | **1.81 px** | −1.74 |
| P2 初版（SIGMA_PER_CELL=0.50） | 2.04 px ← 太粗 | −1.95 |
| 回退后（SIGMA_PER_CELL=0.40） | **1.816 px** | −1.36 |

因此 P2 的门禁改为自相关半宽（目标 1.81 ± 0.15），PSD 斜率降为参考信息。回退后 sigma(D) 曲线与参考最大误差 4.8%，通道相关 0.788（目标 0.79），峰度 3.00。

**7.4 已知残差。** 我们仍有较多中频能量（PSD −1.36 vs 参考 −1.76），A/B 中表现为略柔、带云状调制。这是 v0.4.44 刻意引入的「染料云团」特征，与纯粒子模型（只有 1 px 模糊、没有云团）本就不同。是否要为了贴合参考而削掉这一特征，属于审美决定，留给人工判断。

**7.5 教训。** 先用可测量、可解释、与观感对应的量做靶（自相关宽度），再用多指标交叉验证；不要用单个标量指标去逼近主观观感——它会把你带到统计上达标、看起来完全不对的地方。
