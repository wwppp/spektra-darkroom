1. 版本号与底图完全解耦 (Decoupled Dynamic Versioning)

     - `splash@2x.png` (2560×1440，2.0x 2K/4K UHD 超清)
   - 启动器根据当前主屏幕物理分辨率与设备像素比自动加载最匹配的高分辨率底图，并自适应计算 `devicePixelRatio` 保持 640×360 黄金桌面比例视口，杜绝任何高分屏锯齿与模糊。

   - 坚决杜绝粗厚笨拙的 Semibold 粗体，严格采用纯正高级的 `Segoe UI Regular` 纤细体；
   - 适度调优字体字号与对比度：副标题提升至 24px（#d6dee8），特性标语提升至 18px（#a0aec0），右下角标提升至 17px，左下动态加载文案提升至 17px（逻辑 11px），底栏内绝对几何与光学垂直居中，一眼即辨。

1. 根治 PIL 绘图覆盖 Alpha 通道引发 DWM 分层窗口桌面穿透硬伤
   - **根本诱因透析**：启动底图绘制中，齿孔轮廓（`alpha=10`）、齿孔填充（`alpha=230`）以及版本徽章圆角矩形（`alpha=180`）的绘制操作在 PIL `ImageDraw` 下会直接覆写位图 Alpha 通道，导致整张 1280×720 位图包含 1.8 万余个非 255 的半透明像素；

   - **架构级根治措施**：重写 `generate_modern_splash.py`，所有几何元素全部采用 `alpha=255` 实体不透明填充，底图输出前强制调用 `img.putalpha(255)`，保证整幅画面 100% 绝对不透明，彻底杜绝任何桌面背景与代码透射重影。

   - 彻底修复 `ui/canvas_viewport.py` 片段着色器中的管线拦截时序缺陷：原有着色器在进入分屏对比判决（`u_view_mode == 1, 2, 3`）之前，过早执行了 `if (u_is_bypass == 1) return;`（无胶卷纯直通模式）与 `if (u_is_bypass == 2) return;`（占位预览模式），导致用户在未选胶卷（如默认第一项“无”）或切换加载 RAW 瞬间开启分屏对比时，分割线和对比逻辑被完全短路截断，整张画面沦为相同的一张图，分割线彻底隐形不显示；
   - 重构渲染管线时序：将对比模式（Mode 1, 2, 3）及分割线绘制提升至绝对优先层级，先于一切 bypass 直通处理执行，保证无论是否选择胶卷、是否处于占位阶段，分屏分割线均坚固可见、原片与已修改区域界限分明。

   - 引入物理视口绝对像素尺寸 uniform `u_viewport_size`（`vec2(width, height)`），计算物理像素绝对距离 `abs(v_texcoord.x - u_split_x) * u_viewport_size.x`，彻底摆脱 OpenGL 在动态分支中使用可能返回未定义 0 的 `fwidth()` 偏导数陷阱；

3. 新增着色器物理像素级回归自动化测试

     - 导出的 JPEG / PNG 经 Windows 文件属性、Lightroom 与 ExifTool 读取均 100% 呈现标准度分秒经纬度（如 `34°58'35.4" N, 89°37'5.2" W`）与精准海拔高度；
